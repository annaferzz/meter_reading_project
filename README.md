# Meter Reading Recognition (Система распознавания показаний счётчиков)

## Описание проекта
Система предназначена для автоматического определения и расшифровки показаний бытовых счётчиков (воды) по фотографии.  
Основные этапы:
1. **Детекция области счётчика** — выполняется моделью **YOLOv11** (в примерах используется облегчённая `yolo11s.pt` или обученная `best.pt`).
2. **Кроп изображения** по найденной области.
3. **Оптическое распознавание символов (OCR)** — библиотека `Tesseract` определяет цифры на сегменте изображения.
4. **Возврат структурированного результата** (тип показаний, значение, confidence-score).

Проект разработан на Python 3.13. Все примеры и пути в коде ориентированы на Windows 10, но при необходимости их легко адаптировать.

## Порядок использования
1. Запустите `train_meter_detector.py` для обучения модели:
   - Загружает предобученную YOLO модель
   - Обучает на вашем наборе данных
   - Сохраняет веса в `runs/detect/train_meter/weights/best.pt`

2. После обучения используйте `pipeline.py`:
   - Создаёт экземпляр `MeterDetector` с обученными весами
   - Находит области с показаниями на фото
   - Обрабатывает изображение для улучшения качества
   - Распознаёт цифры через Tesseract OCR
   - Возвращает структурированный результат

## Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
# клонировать репозиторий (пример для PowerShell)
PS> git clone https://github.com/your_name/meter_reading_project.git
PS> cd meter_reading_project

# создать и активировать виртуальное окружение (опционально)
PS> python -m venv venv
PS> .\venv\Scripts\activate   # Windows

# установить зависимости
(venv) PS> pip install -r requirements.txt
```

### 2. Проверка Tesseract OCR
1. Установите [Tesseract-OCR](https://github.com/tesseract-ocr/tesseract) и запомните путь к `tesseract.exe`.
2. Отредактируйте путь к Tesseract в файле `src/config.py` в секции `OCR_CONFIG`.

### 3. Запуск конвейера распознавания
```bash
# пример запуска со встроенным демо-изображением
(venv) PS> python src/pipeline.py
```
По умолчанию скрипт:
* Загрузит веса из `MODEL_WEIGHTS_PATH` (указан в config.py).
* Ставит модель на `cuda`, если доступна GPU-карта.
* Сохранит отладочные изображения в директорию `data/tmp/`:
  - `debug_detection.jpg` - найденные области
  - `debug_crop.jpg` - вырезанная область с цифрами
  - `debug_gray.jpg` - изображение в оттенках серого
  - `debug_thresh.jpg` - после бинаризации
  - `debug_cleaned.jpg` - финальная обработка для OCR

Пример вывода в консоли:
```
Результаты детекции:
Объект 1: water_meter (conf: 0.93)
Объект 2: indications (conf: 0.89)

Отладка OCR:
Результат: {'type': 'indications', 'value': '', 'confidence': 0.89, 'ocr_debug': {...}}
```

## Обучение модели YOLO
Файл `src/train_meter_detector.py` содержит минимальный пример обучения.
```bash
(venv) PS> python src/train_meter_detector.py
```
Параметры обучения:
* `data` — путь к `dataset.yaml` с разметкой в формате YOLO.
* `epochs`, `imgsz`, `batch` — основные гиперпараметры.
* `project`, `name` — директория, в которую будут сохранены результаты.

После завершения обучения веса (`best.pt`, `last.pt`) находятся в `runs/detect/<название_эксперимента>/weights/`.

## Подробности реализации
### `src/detection/yolo_meter_detector.py`
* Класс `MeterDetector` инкапсулирует загрузку модели и детекцию.
* Автоматически выбирает устройство (`cuda`/`cpu`).
* Методы:
  * `detect_meters()` — возвращает список словарей с bbox, вероятностью и классом.
  * `crop_meter_regions()` — сохраняет кропы обнаруженных областей.

### `src/pipeline.py`
* Функция `recognize_digits()` объединяет детекцию и OCR.
* Включает пред- и пост-обработку, хранит промежуточные артефакты для отладки.

### `src/config.py`
Константы для путей, целевых метрик и параметров моделей.

### `src/utils/logger.py`
Унифицированная функция `setup_logger()` для консольного и файлового логирования.
