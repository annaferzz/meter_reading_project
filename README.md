# Meter Reading Recognition (Система распознавания показаний счётчиков)

## Описание проекта
Система предназначена для автоматического определения и расшифровки показаний газовых счётчиков по фотографии.  
Основные этапы:
1. **Детекция области счётчика и индикаторов** — выполняется моделью **YOLOv11s** (в примерах используется облегчённая `yolo11s.pt` или обученная `best.pt`).
2. **Определение показаний** — модель находит области цифр и самого счетчика.
3. **Обработка результатов** — структурирование и валидация полученных данных.

Проект разработан на Python 3.13 с использованием PyTorch и YOLO. Все примеры и пути в коде ориентированы на Windows 10.

## Порядок использования
1. Проанализируйте датасет с помощью `process_dataset.py`:
   - Генерирует статистику по изображениям и аннотациям
   - Создает визуализации распределения классов
   - Формирует подробный отчет в `dataset_analysis.md`

2. Запустите `train_meter_detector.py` для обучения модели:
   - Загружает предобученную YOLO11s модель
   - Обучает на подготовленном датасете с двумя классами (gaz_meter, indicator)
   - Использует оптимизированные параметры обучения (AdamW, lr=0.001667)
   - Применяет расширенные аугментации данных
   - Сохраняет веса в `runs/detect/train_meter/weights/best.pt`

3. После обучения используйте `pipeline.py`:
   - Создаёт экземпляр детектора с обученными весами
   - Находит области счетчика и индикаторов на фото
   - Возвращает структурированный результат

## Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
# клонировать репозиторий
git clone https://github.com/your_name/meter_reading_project.git
cd meter_reading_project

# создать и активировать виртуальное окружение
python -m venv venv
.\venv\Scripts\activate   # Windows

# установить зависимости
pip install -r requirements.txt
```

### 2. Анализ датасета
```bash
python src/process_dataset.py
```

Скрипт выполняет:
* Анализ размеров и разрешений изображений
* Подсчет распределения классов
* Проверку баланса данных
* Генерацию визуализаций
* Создание подробного отчета

### 3. Запуск обучения модели
```bash
python src/train_meter_detector.py
```

Основные параметры обучения:
* Оптимизатор: AdamW (автоматический подбор параметров)
* Learning rate: 0.001667
* Размер батча: 16
* Количество эпох: 100
* Расширенные аугментации данных
* Детерминированное обучение (кэширование на диск)

### 4. Использование обученной модели
```bash
python src/pipeline.py
```

## Метрики качества
* mAP50: 0.66736
* mAP50-95: 0.47635
* Для класса indicator:
  - Precision: 0.84-0.96
  - Recall: 0.69-0.93
* Для класса gaz_meter:
  - Precision: 0.524
  - Recall: 0.364

Подробный анализ результатов доступен в `report.md`
